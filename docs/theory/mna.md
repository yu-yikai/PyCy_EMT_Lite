# 改进节点分析法 MNA 说明

## 1. 为什么使用 MNA

普通节点导纳法适合只包含电阻、电流源等可直接写成节点电流平衡的网络。当电路中出现理想电压源、电感等元件时，仅用节点电压作为未知量会不方便。

改进节点分析法 Modified Nodal Analysis，简称 MNA，在节点电压之外增加必要的支路电流未知量，因此能够统一处理：

- 理想电压源。
- 电感。
- 受控源。
- 后续电力电子开关模型。

## 2. 方程形式

MNA 的基本形式为：

```text
A x = z
```

其中：

- `A` 是系统矩阵。
- `x` 是未知量向量，包括节点电压和必要的支路电流。
- `z` 是右端向量，包括电流源、历史项和电压源给定值。

## 3. 本项目的变量约定

参考节点使用 `"0"`、`"gnd"` 或 `"ground"` 表示，不进入未知量向量。

未知量顺序为：

```text
[所有非参考节点电压, 所有额外支路电流]
```

例如一个电路有节点 `n1`、`n2` 和一个电压源 `V1`，则可能有：

```text
x = [v:n1, v:n2, i:V1]
```

## 4. 基础 stamp 规则

电阻连接在节点 `p` 和 `n` 之间时，写入电导 `G = 1/R`。

电流源方向定义为从 `p` 流向 `n`。它会从 `p` 节点流出，并注入 `n` 节点。

理想电压源需要额外支路电流变量，并增加约束：

```text
V_p - V_n = V_source
```

电容和电感通过数值积分转换为等效电导、等效电阻和历史源，详见 `basic_components.md`。

更详细的各元件矩阵写入位置、右端项符号和代码对应关系，见 `stamp_principles.md`。
