# 已知角度 dq 电流环实施与验证

2026-11-18 · 参考设计草案 · [系统与架构](known-angle-dq-current-system-architecture.md)

1. 固定控制信号、符号、初值、时间表及测量通道。把28号合格R2025a模型与构建、无JVM执行及MAT重载链作为新研究目录的只读输入。保存旧模型、参数、版本和哈希。将已知相角和独立PI嵌入新模型副本，采用标准块并编译。验证6个门极、现有电气支路、浮置两轨和零电感初流。
2. 先用脚本向量运行控制子系统，再接电路做短时探针。导出实际采样电压和电流、角度、dq指令与测量、PI积分、限幅状态、当前和下一参考、载波及实际门极。把积分更新、输出限幅与门极更新分别对齐到整数拍。保存每个版本的原始输出。
3. 短探针通过后准备5 µs与2.5 µs实际参考，固定完整时窗、各物理量预算及同档和跨档指标。先完成参考对自身的初值、KCL、KVL、梯形约束、能量、时序及步长细化检查，再实现简明的Python教学候选。控制端复用 `PIController`、`abc_to_dq`、`dq_to_abc`、载波比较与 `CaseDefinition` 的 `on_step` 回调。验收读取真实两档参考。

| 检查 | 输入与预期 |
|---|---|
| 变换与正方向 | 三相单位正序正弦在 `θ = ωt − π/2` 下给出 `(1,0)`，纯 q 分量反变换后按同角读回 `(0,1)`。短向量最大误差目标 `1e-12`。 |
| PI 积分次序 | 两轴初态为0，输入常值误差。首个正采样输出包含本拍积分增量。按解析前缀核全部样本，短向量容差 `1e-10 V`。 |
| 限幅与恢复 | 以 `e_d=190 V`、零电流、`i_d_ref=−10 A` 触发矢量限幅，输出范数190 V，两轴积分保持。将 `e_d` 回到120 V并令 `i_d_ref=1 A`，下一采样解除限幅并推进积分。 |
| 初始化与一拍生效 | `j=0`积分和参考为0，上管全关。用人工参考阶跃核 `j=20k` 仍为原命令、`j=20k+1` 用新命令。所有观测门极逐位匹配独立比较器，细档半步保持前一门极。 |
| 物理与跟踪 | 完整两档使用电气和控制实际采样点。用预先固定的周期平均窗验证 d、q 指令在分开阶跃后跟踪，初始目标各0.4 A。参考自检、独立波形误差和同档/跨档阈值另封完整协议。 |

短向量验证确认算法和时序。真实短时电路验证确认原生块与测量路径。完整双档对标确认开关模型及教学算例。故障、PLL和电压外环随后各自建立运行场景与参考。

已在28号电气网络上用固定参考验证 `on_step` 接线。两档在100 µs采集源侧相电压和电感电流，105 µs才施加首个新门极。细档102.5 µs沿用旧门极。两档各自与同门极表的独立驱动结果逐行一致。该试验覆盖Python电气网格和回调交接。 [试验记录](../../../development_roadmap/experiments/c1_known_angle_dq_native_startup_20261118.json)

PSCAD 的 EMTDC 控制器已在固定121行输入上通过独立复算。电气网格 200 µs 行触发限幅，300 µs 行解除限幅。窗内5次新参考均在下一5 µs拍生效。下一次试验接入实测电流和前馈电压，检查采样、门极和电气量。 [原生控制记录](../../../development_roadmap/experiments/c1_known_angle_dq_pscad_control_20261118.json)
