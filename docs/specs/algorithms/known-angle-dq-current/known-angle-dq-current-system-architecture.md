# 已知角度 dq 电流环

2026-11-18 · 参考设计草案

在已验收的28号并网桥上，给定电网相角和 d、q 轴电流指令。学习目标是观察 d 轴有功分量与 q 轴无功分量的调节，以及采样、保持和限幅怎样影响跟踪。第一阶段使用同一400 V浮置直流源、三相电源斜坡、每相1 Ω和10 mH、相同的六开关电路。控制器以100 µs采样。门极生成和电气求解属于其外部接口。电路与参考见[28号说明](../../../../validation/cases/grid_connected_vsc_open_loop/README.md)。

| 信号或参数 | 含义与单位 |
|---|---|
| `e_abc` | `grid_a/b/c` 对地电压，单位 V。前馈测量面位于串联 R 前。 |
| `i_abc` | 三相电感电流，电网流向桥为正，单位 A。 |
| `id_ref, iq_ref` | 幅值不变 dq 坐标中的相电流峰值指令，单位 A。 |
| `θ` | 电源相角 `ωt − π/2`，单位 rad，`ω = 2π·60 rad/s`。 |
| `m_abc_next` | 下一门极拍开始生效的三个调制参考，无量纲。 |
| `Kp, Ki` | 首轮试验值取 `L·2π·100` V/A 和 `R·2π·100` V/(A·s)，对应100 Hz平均模型目标。 |
| `Vdc, m_max` | 试验直流源400 V，调制矢量上限0.95。 |

使用幅值不变 Clarke 和 Park 变换。对冻结的正序正弦电源，`θ` 使电网 `e_d` 非负、`e_q` 接近零。正 `i_d` 对应电网向桥输入正有功，按 `Q = 3/2(e_q i_d − e_d i_q)` 约定，正 `i_q` 对应负无功。电压参考 `v_c` 表示调制所控制的平衡三相桥端平均电压。

```text
L di_d/dt = e_d − R i_d − v_cd + ωL i_q
L di_q/dt = e_q − R i_q − v_cq − ωL i_d
u_d = PI(id_ref − i_d), u_q = PI(iq_ref − i_q)
v_cd = e_d + ωL i_q − u_d
v_cq = e_q − ωL i_d − u_q
```

两轴积分器从0开始，PI 的 `lower`、`upper` 均为 `None`。正采样时刻先用本次误差计算试积分 `z_trial = z_prev + Ki·Ts·error`，再用 `Kp·error + z_trial` 计算 PI 电压。若桥端 dq 矢量超过 `m_max·Vdc/2 = 190 V`，保持方向缩放至190 V，这一拍输出限幅值并保留两轴上一拍积分状态。下一采样按当时误差重新判断。反变换后乘 `2/Vdc` 得到三个参考。解耦和桥端限幅的顺序参考[现有单站控制器](../../../../pycy_emt_lite/controls/vsc.py)。

时序以整数门极拍表示。初值时积分和参考均为0，门极上管全关、下管全开。正门极拍 `j=20k` 求解完成后读取同拍电流和电压，计算并锁存下一参考。`j=20k+1` 按新参考与当拍载波比较，当前参考维持到下次生效拍。5 µs和2.5 µs电气网格共用5 µs门极时钟，细档中间半步保持门极。原生模型须展示控制采样点的实际读取值与下一拍施加值，作为反馈路径的因果证据。

```text
电压、电流和已知角度 → abc/dq → 电流误差和双 PI
                        → 电压前馈与交叉解耦 → dq 限幅 → abc 调制
                        → 参考锁存与一拍生效 → 5 µs 载波比较 → 开关电路
```

首轮运行场景为0–20 ms源斜坡、40 ms处 `id_ref` 从0升至2 A、80 ms处 `iq_ref` 从0升至1.5 A。试验采用从电气数据计算的60 Hz周期平均量，在各阶跃后至少三个周期检查误差。初始跟踪目标为两轴周期平均偏差各不超过0.4 A，保留完整开关纹波供物理检查。阈值和运行窗在参考建模前单独封定。限幅及恢复先用控制器输入向量单独检查。

Simulink 实现优先用已有离散基本块构成试积分与条件写回。`Unit Delay` 的初始值与同速延迟行为已有文档依据，100 µs 到5 µs的实际数据交接须通过本机R2025a编译与日志核对。电气求解仍使用28号已验证的梯形法。 [MathWorks Unit Delay](https://www.mathworks.com/help/simulink/slref/unitdelay.html) · [MathWorks Discrete-Time Integrator](https://www.mathworks.com/help/simulink/slref/discretetimeintegrator.html)
