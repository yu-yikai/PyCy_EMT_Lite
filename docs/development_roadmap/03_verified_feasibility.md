# 最小可行性证据

日期：2026-11-04。基线为 `a03a450`；实验不是正式新增算例，也不是商业平台参考数据。

## 级联 RC

拓扑为 src—R1—n1—R2—n2，C1/C2 分别从 n1/n2 接地。R1=R2=10 Ω，C1=C2=100 µF，零初值。独立 KCL：

```text
C1 dv1/dt = (u-v1)/R1 - (v1-v2)/R2
C2 dv2/dt = (v1-v2)/R2
```

执行 `.tmp/venv-py3145/Scripts/python.exe -m docs.development_roadmap.experiments.cascaded_rc_probe`。
5 V 常值输入、0–10 ms、步长20/10/5 µs，以矩阵指数精确推进两个状态，未复用 companion/stamp。

| 方法 | 最大电压误差 V（依次细化） | 误差比 |
|---|---|---|
| TR | 1.183954e-4 / 2.959877e-5 / 7.399290e-6 | 4.000012 / 4.000217 |
| BE | 1.486993e-2 / 7.501466e-3 / 3.767667e-3 | 1.982270 / 1.991011 |

两节点逐样本 KCL 均小于1e-10 A。结论：现有基础元件足够，无需修改MNA或积分公式。这个实验使用阶跃前的零电容电压与一致电流；不把首步当作额外初始化积分。

官方 `simscape/CascadedRCCircuitInSimulinkAndSimscapeExample` 已由 MATLAB R2025a Update 1 实际获取并运行，Simscape原生波形已导出。模型包含每只电容1 µΩ ESR，PyCy候选使用理想电容，差异必须记录；不能把官方错误的单向级联 Simulink 分支当作物理网络参考。

`validation/cases/cascaded_rc/manifest.json` 在候选实现前规定四信号、四时间窗、物理基值与阈值。源跳变使用显式事件，保留真实时刻，不拟合时间偏移。正式实现、内部测试和真实数据对比属于后续实施任务，不能因本探针通过就算完成。
