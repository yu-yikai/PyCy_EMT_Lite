目标是核实控制和电路实际生效方式，不新增教学算例、不修改12、不回放PyCy门极驱动原生电路。

## 独立控制的精确定义

默认12使用`n*5e-6`时间网格，在每次网络求解前按当前时刻写开关，TR保留前一步电感状态，没有自动开关事件投影。参考实现必须明确自身调用次序并记录实际活动电阻，不能把控制输出标签等同于已生效开关。

短探针由原生`TIME`直接驱动控制，并同时记录网格观察量。先核清平台时间算术，不预先把原生时钟修正成PyCy时钟：

```text
电气步号 j = INT(TIME / native_h + 0.5)       # TIME>=0时的最近网格观察量
网格观察量 t_grid = j * native_h
m = INT((TIME + 1e-15) / 100us)
t_hold = m * 100us
ref_p = 0.8 * SIN((2*pi*60)*t_hold + phase_p)
phase_carrier = MODULO((TIME - 0.5ms)*1000, 1)
carrier = 4*phase_carrier-1  (phase_carrier<0.5)
          3-4*phase_carrier  (其余)
g_upper_p = (ref_p >= carrier)
g_lower_p = 1-g_upper_p
R_switch = 0.001*g_closed + 1e9*(1-g_closed)
```

短探针电气与控制步长相同，均5µs。将来细化时如何保持5µs控制网格，须在实际时间映射核定后写入正式协议；不能直接在更细电气网格重算门极并称为同一输入。
相位来自原源码的`pi/2`、`-2*pi/3+pi/2`、`2*pi/3+pi/2`及其实际双精度常量；不能换成另一组度数后宣称逐位相同。
`MODULO`的正余数与Python `%`一致，Fortran `MOD`在启动负自变量处不同。安装库比较器为严格`A>B`；用A=carrier、B=ref、OHi=0、OLo=1、Pulse=0、INTR=0、conv=1保留`ref>=carrier`。

离线独立标量计算重现既有40001点六路门极，A相仅在n=10/10010/20010/30010有数学相等边界。按旧原生打印时间重算会翻转其中后三点，故须同时保留原TIME、j、t_grid、m、ref/carrier和实际g/R；不能移相、删掉边界或在电流比较中排除这些点。数学相等不自动认证两平台逐位相同，实际差异须逐点解释。

## 电路元件与数值方法

独立关闭项目`detect_chatter`、`remove_chatter`、`interpolate_switching`，并设置`use_ideal_branch=False`、保留其他位，保存设置前后字典/XML/生成配置。只关detect并不保证无半步处理。核全部TR边沿和首步电感方程，不凭波形小于2%就认证方法一致。

原生通道至少包括TIME/控制步号/保持步号、载波、三相ref、六门极/电阻、实际Vs、六支路电压电流、三相负荷电流、三极点/中性点电压。保存原生kV/kA/Ω，不用显示单位或名称猜SI值；明确一次性转换和方向。
