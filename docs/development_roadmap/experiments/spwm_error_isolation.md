结构推导的三相上/下门极与全部真实记录仍逐点相同。

## 四个预先定义的因素

G为原12门极→结构推导门极；M为TR→BE；P为负荷并联电导0→1µS；D为加入真实记录导出的器件电压残差。四项全部16种组合都保留。

双向开关可写成极点电压`p=E(g)-r*i`，其中`r=1/(1000+1e-9)Ω`，`E(g)=400*(1000*g+1e-9*(1-g))/(1000+1e-9)V`。
用原真实门极、电流和极点电压定义`d=p_native-E(g_native)+r*i_native`。它合并了实际器件压降、通道/二极管及泄漏差异；前次已核实其主要部分约为±0.8V。

每个组合先从`E(g)+D*d`减去三相均值得到驱动`u`，再计算：

```text
k = 1 + r*Gload
L*dj/dt = u/k - (R+r/k)*j
v_load = (u-r*j)/k
i = j + Gload*v_load
```

`j`是串联RL电流，`i`是包括并联支路的总电流。R=1Ω、L=1mH和所有初值不变；用明确的TR或BE公式离散。
**D是已观测到的电压历史，不是预测IGBT/二极管导通的器件模型。**含D的混合组合复用同一历史，只能解释给定输入下的线性响应，不能当成另一门极下的物理商业仿真；没有用观测电流符号驱动新候选。

下表遵守事先规定的G→M→P→D路径，NRMSE仍用150A工程基值。全窗列给出三相范围，稳态列列出全部三相。

| 只换G | 0.50056%–0.50559% | 0.50274% | 0.50528% | 0.50516% |
| 再换M | 0.44705%–0.45261% | 0.44949% | 0.45217% | 0.45205% |

最后一行全点最大电流差2.42e-12A，是把已记录电压残差代回方程得到的诊断闭合，不能据此认证器件等效或宣布PASS。
原全窗A相峰值误差12.37A也完整保留；原验收的10A限值仅用于既定0.1–0.2s窗，没有扩大或缩小其范围。

固定路径的稳态电流变化量RMS依次约为：G 4.172–4.271A，M 0.2565–0.2567A，P 0.0001525–0.0001526A，D 0.6743–0.6784A。
它们不能按RMS相加：G与D的变化部分抵消。仅加入D而不换G，稳态误差反而为2.780%–2.844%。全部16种组合均在数据和JSON中，没有只选较容易接近参考者。

遍历24种加入顺序，单项对稳态总RMSE的减少量范围为：G +3.229至+4.270A，M −0.00327至+0.25670A，P −0.0000850至+0.0001521A，D −0.1971至+0.6784A。
G与M的二阶波形交互RMS约0.0685–0.0697A；控制边沿变化会改变两种积分方法的差值。因此这里没有给出唯一“各占百分之几”的物理归因。
报告保存了各波形增量间的带符号内积，按平方项加交叉项重建总均方误差，残差小于4.5e-13A²。
