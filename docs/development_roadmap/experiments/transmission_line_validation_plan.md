# A7：50T线路的独立物理验收推导

默认真实运行1081个原生样本，间隔约12.22–66.25 ps；源正弦残差6.34e-13 V、终端Ohm定律残差1.03e-15 A，记录位于 `local_reference/transmission_line/`。最终外部参考按独立10/5 ps最大步长、RelTol=1e-8、AbsTol=1e-10细化，必须先通过自身收敛条件，不能据PyCy误差选择参考设置。

这是有限维集中参数T线。它与π梯级、连续分布线路及Bergeron模型的方程不同，不承担后两者的验证。没有控制器：u为源电压，w为空；y为冻结的端口电压/电流；z为内部储能状态与损耗审计量，均用SI单位。

## 方向、节点与官方图例纠正

全局边界命名n0至n50，第k段左/右端为n(k−1)/nk，电容中点记ck。所有候选串臂电流定义为向右，负载电流为n50流向地。

SSC原件右臂的原生正方向却是 `p2 → r2 → l2 → 中点`。因此原生 `l1.i` 等于右行左臂电流，`l2.i` 等于右行右臂电流的负值。不能将相邻段原生l2与l1同号相加检查等流；其和应为0。能量的平方项不受反号影响。

官方绘图脚本把 `S2.T_5.p2.v` 标成Segment25，按串接顺序它是n15；真正n25是 `S3.T_5.p2.v`。n50为 `S5.T_10.p2.v`。须保留原脚本错误证据，不改原模型或照抄标签。

冻结的六个正式量为n0/n15/n25/n50电压、`i:L1_left`和`i:Rload`。原生输入电流取 `S1.T_1.l1.i`，负载右行电流取最后一个右臂电流的负值或已核定方向的负载支路。中间电流、全部C/L状态可用于内部审计，不新增正式映射。

## 独立101状态方程

以下直接由KCL/KVL推导，不调用PyCy stamp、companion或历史状态更新。

令v_k为第k个电容中点ck电压，k=1…N；j_0为源至c1电流，j_k为ck至c(k+1)电流，j_N为cN至负载电流，均向右。相邻两个半臂之间没有分支，因而其右行电流相同；在独立oracle中可将这两个半R/L精确相加。保留50个电容电压和51个电感电流，共101状态。生产候选仍保留原50T的100个电感，不作合并。

对本例的均匀参数：

```
c * dv_k/dt = j_(k-1) - j_k - g*v_k                     k=1..N
(l/2) * dj_0/dt = u - (r/2)*j_0 - v_1
l * dj_k/dt = v_k - v_(k+1) - r*j_k                    k=1..N-1
(l/2) * dj_N/dt = v_N - (r/2 + Rload)*j_N
```

令D的第k行仅有D[k,k−1]=1、D[k,k]=−1。C=cI，G=gI，L=diag(l/2,l,…,l,l/2)，R=diag(r/2,r,…,r,r/2+Rload)。则

```
x = [v; j]
dx/dt = A*x + b*u
A = [ -C^-1*G       C^-1*D  ]
    [ -L^-1*D.T    -L^-1*R  ]
b = [0; L^-1*e_0]
```

零初值为x(0)=0，不以正弦稳态相量代替。为避免量纲与纳秒尺度造成不良数值尺度，令z=[v;50*j]，时间单位选ns；使用相似变换后的矩阵，所得物理响应完全相同。

再增加s=sin(ωt)、q=cos(ωt)，s(0)=0、q(0)=1：

```
d/dt [x] = [ A   10*b    0 ] [x]
     [s]   [ 0     0     ω ] [s]
     [q]   [ 0    -ω     0 ] [q]
```

103维增广矩阵指数给出完整启动瞬态，可计算一次 `P=expm(A_aug*h)` 后递推，也可用 `expm_multiply`。正弦/余弦状态是已知激励的解析表示，不是拟合频率、相位或延迟。检查P(h/2)²与P(h)以及激励状态对已知正弦的残差；这些结果是独立数学解，不能冒充商业平台导出。

注意v_k为电容中点，不是右端口nk。均匀相邻半臂R/L完全相同，精确有 `v:nk=(v_k+v_(k+1))/2`（1≤k<N）；端点 `v:n0=u`、`v:n50=Rload*j_N`。此处平均来自电路对称关系，不是对记录波形进行平滑。两端电流分别j_0/j_N。

## 传递矩阵用于不同角度的交叉检查

单段总串联阻抗Z=r+s*l，并联导纳Y=g+s*c。以输入/输出电流均向右定义端口向量，则

```
T = [1 Z/2; 0 1] * [1 0; Y 1] * [1 Z/2; 0 1]
  = [1+Z*Y/2, Z*(1+Z*Y/4); Y, 1+Z*Y/2]
det(T)=1
[Vin; Iin] = T^50 * [Vload; Iload]
```

令T^50=[A B; C D]，本例理想电压源及电阻终端满足

```
H(s)=Vload/Vsource=1/(A+B/Rload)
Zin(s)=(A*Rload+B)/(C*Rload+D)
```

用该频响独立检查状态矩阵的 `(sI−A_state)^−1*b`，包括200 MHz和预先选取的数个频率。它不适合直接与50 ns零初值波形作“稳态相量误差”验收；若另作稳态正弦研究，须事先另定时长和初始化协议。

即使忽略小R/G，令η=ω√(lc)，有限对称T仍有 `θ=2asin(η/2)`，而非θ=η。实际200 MHz下η=0.62831853、θ=0.63914191 rad/段；无损近似相位延时25.43065 ns、群延时26.33324 ns。Bloch阻抗约47.46851 Ω，所以50 Ω终端的反射系数仍约2.597%，不严格匹配。名义连续线路25 ns只作教学尺度，不作精确到达时刻判据。有限梯级的解析响应也不具有Bergeron那样的严格纯延时前零响应。50 ns仅两倍名义单程时间，不能预设已经充分稳态。

## 能量、损耗和方向的独立检查

令w_0=w_N=l/2，其余w_k=l；ρ_0=ρ_N=r/2，其余ρ_k=r。只在线路储能：

```
E = (c/2)*Σv_k² + (1/2)*Σw_k*j_k²
P_R = Σρ_k*j_k²
P_G = g*Σv_k²
P_load = Rload*j_N²
P_source = u*j_0
dE/dt = P_source - P_R - P_G - P_load
```

以原100个电感分别计算的储能必须与合并状态公式一致。输入端允许瞬时回馈，不能强制每点P_source≥0；所有电阻/漏导损耗和负载耗散必须非负。源原生吸收电流与j_0相反时明确转换。

连续工作平衡使用真实时间权重的积分，检查 `E(t)-E(0)+∫(P_R+P_G+P_load)-∫P_source` 的全时间最大残差，分母用正的输入/损耗/储能工程尺度，不能用恰好接近0的净功归一化。冻结相对限值0.005。

还有两个独立的离散恒等式可以帮助区分物理损耗与数值误差。TR在每步采用电压、电流各自端点平均值的乘积，满足 `ΔE=h*(P_source,mid−P_R,mid−P_G,mid−P_load,mid)`；不能把端点功率的梯形均值误称为该恒等式。BE使用本步末端功率，多出的非负数值耗散为 `(1/2)*Σc*(Δv)²+(1/2)*Σw*(Δj)²`。这些离散平衡不代替expm波形比较或真实参考。

## 已冻结的验证顺序

1. 核定实例、端口与原生日志初值，先冻结manifest和parameters；本轮对应 `3761a21`，已完成。
2. 单T/链连接检查：半臂各占一半总R/L、shunt C/G不分半；检查所有边界的等流和中点KCL，冻结绝对限值1e-8 A。生产100L均向右，原生右臂反号只在参考映射转换。
3. 全50T完整0–50 ns启动瞬态：TR10 ps对独立增广expm，六个正式量电压最大误差≤0.05 V、电流≤0.001 A。另检查全部101状态，避免只看端口掩盖错接段号。
4. TR按20/10/5 ps细化，分别对同一独立精确瞬态计算误差，两次误差比均≥3；BE同组步长仅作一阶数值耗散与收敛说明。不能用TR/BE互相比代替真值。
5. 初值、方向、KCL、正耗散及能量平衡全部通过，独立教学脚本执行成功后，才进行真实参考比较。
6. 供应商10/5 ps最大步长自身细化差须小于正式最大绝对误差限值的1/10；原生不等步长数据保留，以绝对时间比较，零移相/振幅/传播延迟拟合。
7. 最终六量全窗采用10 V/0.2 A固定基值，NRMSE≤0.003且最大误差≤0.05 V/0.001 A，全部成立才可正式完成。失败保留失败报告，不能按观察结果放宽。

教学重点是T段的耦合、正确的中点/边界区分、有限梯级色散、输入与负载功率以及守恒；性能只沿用现有稠密LU `linear_solver_mode='reuse'`。本任务不引入稀疏求解、延时元件、自动二极管或新的线路核心类。
