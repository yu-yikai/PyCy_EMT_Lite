# A4：外置三电感T等效变压器的独立验收

## 物理映射

使用原五网络 `CompareCircuits.slx` 的第三个纯电气T网络，采用官方Live Script的实际实验值：ratio=N1/N2=0.2，l1=0.01 H，Lm=0.1 H，l2=0.25 H，源串阻Rs=1 Ω、负载Rl=1 Ω，1 V在2 s阶跃，停止8 s。原生三电感初值均0。不得混用SLX备用的Lm=1 H、阶跃100 s配置。

```text
src -- Rs -- pri_in -- L1 -- core_p -- ideal T(.2:1) -- sec_p -- L2 -- load -- Rload -- 0
                               |
                              Lm
                               |
                               0
```

理想T两个负端分别接明确参考0。现有 `SinglePhaseTransformer` 只保留理想变比，内部漏R/L均0、内部magnetizing_inductance=None、core_loss_resistance=None；三个电感完全外置。例09的聚合励磁支路位置不同，不是本题候选。外置励磁电流必须记录 `i:Lm`，不能用未启用的 `i:T1:magnetizing` 输出代替。

令is=i:L1，从源流向core_p；il=i:L2，从sec_p流向负载；im=i:Lm，从core_p流向地。T端口电流均以流入正端为正，因此 `i:T1:primary=il/a`，`i:T1:secondary=-il`，并有 `is=im+il/a`、`vp=a*vs`。理想块瞬时吸收功率 `vp*ip+vs*isec=0`；它没有储能或损耗。

MATLAB原生映射已从真实日志核定：`Controlled_Voltage_Source3.v`为激励；`Subsystem_Reference2.Ideal_Transformer.v1/v2`为core_p/sec_p电压；`Resistor5.v/i`为负载；源流向T的电流等于 `-Controlled_Voltage_Source3.i` 和原生l1.i_L；原生l2.i_L方向与il相同，`Subsystem_Reference2.Lm.i_L`与im相同。旧118点仅供可行性和方向核定，正式参考需独立精化。

## 两状态与阶跃精确解

由三个电感和理想变比约束消去代数量，取x=[is,il]，有

```
im = is-il/a
vp = Lm*(dis/dt-dil/dt/a)
vs = vp/a
u = Rs*is + l1*dis/dt + vp
vs = l2*dil/dt + Rl*il

M*dx/dt + R*x = [u,0]
M = [[l1+Lm, -Lm/a],[-Lm/a,l2+Lm/a²]] = [[.11,-.5],[-.5,2.75]]
R = diag(Rs,Rl) = I
```

M对称正定，det(M)=0.0525 H²。A=−M⁻¹R，x∞=[1,0]；令τ=t−2：阶跃前x=0，阶跃后 `x=x∞-expm(A*τ)*x∞`。通过 `dx/dt=M⁻¹([1,0]-R*x)` 重建vp/vs/load电压，不从采样电流作数值微分，也不复用生产stamp/companion。

Rs=Rl=1 Ω时，两模态时间常数为0.01847600091 s和2.84152399909 s。若μf/μs为这两个时间常数，负载电流可进一步写成

```
il(τ) = [0.5/(μs-μf)] * [exp(-τ/μs)-exp(-τ/μf)]
τpeak = μf*μs/(μs-μf)*ln(μs/μf)
```

解析峰值位于t=2.093647085 s，约0.1702573184 A。8 s时τ=6 s，is≈0.9960754915 A，il≈0.02143977808 A，im≈0.8888766011 A。不能要求8 s的il已经为0。只有渐近极限才有is→1 A、il→0、im→1 A及core电压→0。

该直流阶跃只研究线性等效回路；不能据此宣称真实铁芯允许持续直流、没有饱和或已验证磁滞。理想变压器单独接同样Rs/Rl时负载电流立即跳至a/(Rs+a²Rl)=0.1923076923 A且持续，正是缺失有限Lm/漏感时不同的简化模型。

## 阶跃左右侧与初值

使用现有显式事件机制在2 s将常值电压源0→1，不用含隐藏跳变的callable代替。三个电感电流和总储能连续，事件前后都是0；内部电压允许有限跳变。2 s右侧的独立解析量为

| 量 | 右侧精确值 |
|---|---:|
| dis/dt | 52.38095238 A/s |
| dil/dt | 9.523809524 A/s |
| dim/dt | 4.761904762 A/s |
| v:core_p | 0.4761904762 V |
| v:sec_p | 2.380952381 V |
| v:load | 0 V |

这些值来自M方程，不是从左/右侧混合采样拟合。必须检查唯一右侧事件行、事件日志before/after值、储能状态连续性，并用一步外的精确解验证后续推进正确。可增加非整步时刻的短时内部测试，确认insert策略保留事件时刻；不得因此改正式2 s协议。

## 能量与独立守恒

```
E = .5*l1*is² + .5*l2*il² + .5*Lm*im² = .5*x.T*M*x
dE/dt = u*is - Rs*is² - Rl*il²
```

两个电阻都是绕组外部支路，不命名为未建模的绕组铜损或铁损。全部耗散非负，理想T零净吸收功率；源允许根据瞬态发生回馈，不要求每一点输入功率为正。渐近储能0.055 J；8 s的真实有限时间解析储能约0.04452337054 J，两个数不能混用。

使用真实时间间隔，恢复显式事件区间终点的左侧源值，再积分源功与损耗，检查全时间累计残差。归一化采用正的输入工作/损耗/储能尺度，不除以接近0的净工作；冻结相对限值0.001。TR额外核对基于端点平均电压与平均电流乘积的离散能量恒等式；BE可另检查非负数值耗散，均不代替精确解或真实参考。
