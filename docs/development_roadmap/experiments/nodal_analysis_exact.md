# 官方节点分析例的独立精确解

来源为 MathWorks DC Circuit Analysis v2.2.2 的 `NodalAnalysisExample.slx`，原件哈希和完整物理接线见[常数JSON](nodal_analysis_exact.json)。本文件用于内部物理验证，不冒充Simulink/PSCAD数值数据。

以g为0 V、s为3 V；支路正向为R1:s→b、R2:s→a、R3:a→b、R4:a→c、R5:b→d、R6:b→g、R7:d→g。电阻依次为200、140、330、2000、330、50、50 Ω。[官方电流源](https://www.mathworks.com/help/simscape-electrical/ref/currentsource.html)参数正向由负端流向正端，本例为d→c的0.2 A，故c→d支路电流为−0.2 A。

四个未知电压满足独立KCL：

```text
(a-3)/140 + (a-b)/330 + (a-c)/2000 = 0
(b-3)/200 + (b-a)/330 + (b-d)/330 + b/50 = 0
(c-a)/2000 = 1/5
(d-b)/330 + d/50 = -1/5
```

先消去c、d，得到c=a+400、d=(5b−330)/38，再得到两式`47a−14b=1023`、`−380a+3845b=−1419`。解为a=118593/5315、b=9759/5315、c=2244593/5315、d=−17949/2126 V，即22.31288805、1.83612418、422.31288805、−8.44261524 V。c的高电压来自200 mA流过2 kΩ支路所需的400 V压差，理想电流源没有合规电压限制。

每个电阻按`i=(v_p−v_n)/R`求电流，电压源s→g电流由s节点KCL得到70227/531500 A（0.1321298213 A）。Vs吸收0.3963894638 W；Is供电约86.15110066 W。电阻总损耗为45578629/531500 W（85.7547111947 W），等于两电源净供给；所有元件吸收功率之和严格为0。

JSON用Python标准库`fractions.Fraction`进行四阶Gauss–Jordan消元，所有矩阵、注入向量、支路电流/电压/功率及KCL残差均保存为精确分数和SI单位小数。没有导入生产组件、stamp或求解器。每个节点的精确KCL残差及全网功率残差均为0。该静态例不检验积分精度、暂态或事件功能。
