## 1. 实施原则与任务边界

当前没有新确认P0/P1物理方程或积分缺陷，不建立“重写数值内核”阶段。整改优先解决已复现输入行为、明确文档错误和有辨识价值的控制状态测试。其余为P3可选改进，不能为了完成清单强行增加依赖、抽象或功能。

9项登记统计为P2四项、P3五项。AUD-008沿用历史F0/F1已经核定的方向；不是新Bug，也不视为已经获准实施优化。历史R12的FAST用途、默认PLL80/1000、rebuild默认、小网络precompute及HVDC拒绝precompute等边界保持。

每个下列任务应成为一个可独立审查的提交；双语同一问题在同一提交内修正。开始时记录HEAD和工作区差异，保留用户修改。先写最小反例/独立预期再改实现；不以放宽容差或改物理预期使测试通过。后续若真的发现新数值缺陷，应独立编号、推导、复现、修复，不能混入本计划的格式或文档提交。本轮没有提交或推送；下列“提交”是未来变更的建议组织方式。

推荐顺序：

**依赖：** 无。**收益：** 消除有限且残差正常的错误开关状态选择，改善文本输入和调试。
**风险：** 任意truthy对象的未声明用法会被拒绝；避免把合法bool和0/1意外拒绝。无需新增第三方依赖或配置解析框架。
**验收：** 参数化正反例能区分当前实现和修复；常量及运行期改值分别验证，标准故障/断路器事件全过；运行期失败不得导出被当作合法状态的新结果。先跑定向switch/events，再跑快速回归；保留数值结果和事件日志。

**建议独立变更：** “拒绝故障/断路器非法二值状态”。生产物理方程无变化。若未来新增P0/P1，应优先于本期并另立独立修复，本轮没有预设这种缺陷。

## 7. 明确不列为当前必做的扩展

下列证据边界在后续具有明确教学/验证需求时独立选题，不按“全仓规范化”自动扩张：

| 方向 | 最小研究起点 | 启动/验收条件 |
|---|---|---|
| 饱和回程/周期/能量 | 负向过零和周期激励的独立简化模型参考 | 先声明滞后模型可解释量；不直接换成真实铁芯曲线 |
| 衰减Bergeron | 匹配端口的幅值与能量参考 | 不扩为频变互感线；固定整步语义 |
| 机组更广控制工况 | AVR/调速器达到/解除限制的连续参考 | 使用现有简化机组假设；不默认设备级等价 |
| 精细HVDC控制精度 | 固定PWM/物理参数的同窗比较与独立目标 | 保留原RMS、低频与纹波区分；不重新采用已拒绝候选或降阈值 |
| 条件数/缩放/稀疏 | 具体病态案例和真实矩阵规模测量 | 衡量成本、教学收益及误差；不未经测试替换LU |
| 安全/保存格式增强 | 具体损坏数据或并发写威胁模型 | 原子保存/schema/CSV事件等是新能力，另定兼容策略 |

没有本轮证据要求新JIT/GPU/C++扩展、并行仿真框架、复杂稀疏后端、图形建模器或新增包依赖。
