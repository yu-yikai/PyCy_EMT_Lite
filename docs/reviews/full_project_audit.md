### AUD-001：非法状态会静默选择另一电路

Fault和Breaker构造期只验证电阻，stamp/output直接使用Python真值。字符串"False"、2、NaN均为真；10V加1Ω故障输出state=1、i=10A，合法False对照为0。Breaker.closed="False"也已实际复现导通。结果可以完全有限并满足被错误选择电路的KCL，残差无法发现用户意图差异。由于触发条件违反已标注bool类型，本轮定为P2输入保护缺口，而不是宣称合法bool输入的电气方程错误。

~~~python
from pycy_emt_lite import Circuit, Fault, Resistor, SimulationConfig, Simulator, VoltageSource
parts = [VoltageSource("V", "n", "0", 10.0), Resistor("R", "n", "0", 10.0),
         Fault("F", "n", 1.0, enabled="False")]
row = Simulator(Circuit.from_components("flag", parts), SimulationConfig(.1, 0)).run().rows[0]
print(row["state:F"], row["i:F"])  # 当前输出1.0 10.0
~~~

最小方案：明确bool/np.bool_与是否接受0/1，参照IdealSwitch的二值契约，在构造和实际采样处拒绝字符串、NaN、2、数组等。优先用小私有校验函数；不引入配置框架。
兼容性：合法bool及标准事件保持；任意truthy输入的未声明用法将显式失败。验证：Fault/Breaker参数化合法/非法状态，检查首次求解前失败；运行期改状态若仍支持，也须具名报错且不把失败状态记作合法结果。参考tests/test_power_electronics.py:144–166现有IdealSwitch辨识方式。细节见元件证据第3节。

### AUD-002：负Ki已修源码，推导仍教旧判据

中英推导725–726称源码在“上限且e>0/下限且e<0”冻结。blocks.py:118–127实际按Δxi=Ki·e·h的符号决定保存；通用PI支持负Ki。不能用PLL增益限制替代通用PI契约。

~~~python
from pycy_emt_lite.controls import PIController
pi = PIController(0.0, -1.0, lower=-1.0, upper=1.0)
pi.reset(2.0)
~~~

原因是历史I16修复后说明未同步；影响是学习者照文实现会再次引入方向错误。最小修复为双语同位置改成积分增量方向，并准确说明Ki=0。

## 6. 关键数值算法审查

### 6.1 MNA与方向

设a为支路关联向量（p为+1、n为−1，地省略），u=aᵀv，i由p到n。全网形式为：

~~~text
[G  B] [v] = [j]
[C  D] [i]   [e]
~~~

普通电压源的B/C为关联列/行；含理想变比和控制端口时不必强制矩阵对称。

| 物理/离散方程 | 矩阵贡献 | 代码 |
|---|---|---|
| R: i=Gu | A+=G aaᵀ | stamping.py:125；basic.py:66 |
| I源: i=I(t) | b-=aI | stamping.py:137；basic.py:106 |
| V源: u=E(t) | KCL列+=a；支路行+=aᵀ；b[k]+=E | basic.py:163 |
| C: i=GCu+H | A+=GC aaᵀ；b-=aH | basic.py:223–280 |
| L: u−Req i=H | KCL列a；支路行aᵀ及−Req | basic.py:319–377 |

电压源支路电流定义为流入其正端；当u>0且向外供电时i<0。一般应以u*i作为吸收功率、−u*i作为向外供给功率，不能仅凭电流符号判断所有源的发电方向。源方向/KCL测试见test_basic_components.py:201,229；输出重名有明确拒绝，不会覆盖节点或其他元件。

悬浮网络、冗余理想源、初值冲突和非唯一电流得到奇异/欠定/约束冲突诊断；程序不擅自加泄漏改变物理模型。失败信息包含时间、求解器或具体元件/stamp/update/outputs/callback阶段，原cause保留。尚无完整图拓扑定位器，纯求解失败未必列出全部致因元件；当前没有必要以此新增大型诊断系统。

### 6.2 TR、BE及时间层

对实际正区间h、左端状态u0/i0：

| 模型 | TR | BE |
|---|---|---|
| C，i=C du/dt | G=2C/h；H=−G u0−i0 | G=C/h；H=−G u0 |
| L，u=L di/dt | Req=2L/h；H=−Req i0−u0 | Req=L/h；H=−Req i0 |
| 串联RL | u−(R+Req)i=H，历史保存纯电感uL | 同一关系 |

伴随参数每步按实际h重算，update在求解后读取旧历史再保存。独立C/L、三相RL、π线与变压器漏感的符号对应一致。本轮未更换算法或放宽容差。

时间配置只支持start=0、整基础步终点；insert插入事件产生不同h，quantize_up延后，require_aligned拒绝。8ULP处理浮点对齐，非正规基础步长和超过500万步分配在前端拒绝。Bergeron额外要求实际固定网格及整步时延，不能将一般RLC的非均匀能力外推给它。

在t=0和事件右侧，C固定电压并临时加电流未知量，L固定电流；并联C/电感割集出现相关行时，归一化QR选独立约束，构造W A0=0，对A0 xdot=D0 x+d0左乘W补W D0 x=−W d0。仅求一次导数，不是任意指数DAE。源导数只在必要相关约束调用，不用任意差分估计。解后逐行检查原约束，必要时只做一次残差修正。stamping.py:35–122与双语推导13节对应。

事件先按旧网络积分至左侧，再执行同刻事件、固定储能求右侧，保存新配套iC/uL，每时刻一行且回调一次。test_events.py:226,255,278,293验证状态连续、同刻顺序、断路冲突；本轮另用非平衡机组初值在0.012/0.0123/0.03s触发故障，两种机组共6组事件右侧动态状态跳变量均0，避免只测平衡点。

TR无损线性储能满足ΔE=h·平均u·平均i；BE满足h u1 i1=ΔE+C(Δu)²/2或L(Δi)²/2。BE数值耗散不等于电阻损耗；TR在不连续激励附近可能振铃，不据此认定伴随式错误。只保存事件右侧和抽样后的结果不足以直接做跨事件逐步能量账，现有指标及文档已说明。

### 6.3 求解器与缓存

稠密带主元LU适合现有小矩阵，未用显式逆矩阵。[SciPy lu_factor](https://docs.scipy.org/doc/scipy/reference/generated/scipy.linalg.lu_factor.html)与[lu_solve](https://docs.scipy.org/doc/scipy/reference/generated/scipy.linalg.lu_solve.html)的存储/主元和有限性接口与调用对应。

rebuild默认逐次LU；reuse以完整A逐元素精确相等判定复用上一份LU，A1→A2→A1重新分解三次；precompute只准入核定精确类型与完整有限状态族，复制数值模型不调用真实源/门极/事件/回调。未知状态/h/系数明确拒绝，没有循环内补分解或静默降级。actual h、一致增广矩阵、角度/饱和系数变化都不能仅靠拓扑键忽略。

precompute默认最多1024状态，另有1GiB数值估算/累计预算；预算含A/LU/主元/准备字节键与临时空间估计，不是进程RSS保证。自动枚举到奇异不可达组合也会拒绝，可用完整明确的可达声明集合；HVDC入口已拒绝precompute，不能以缩短时长偷偷绕开范围。tests/test_solvers.py覆盖真实调用次数、状态/步长、缓存变化、保护入口、内存预检和三策略逐行等价。

残差先按A/x尺度归一，检查非零量缩放下溢、有限性、解形状、绝对及相对诊断；两种残差均超限才拒绝。小后向误差不等于小前向误差；_conductance_current另检查相近电压/历史相消的表示尺度，超过1e−7A+0.1%|i|即拒绝测量。这仍不是所有病态网络误差界。当前不建议每步自动cond：成本高且不能修复模型/尺度；只在具体拒绝案例需要时做可选一次性诊断。未发现证据要求替换LU或立刻引入稀疏求解。

factorization_count统计实际分解，solve_count记录实际求解调用；初值修正会增加求解次数。修正后last_diagnostics对应修正方程而非最终原方程，当前文档已说明。自定义后端遵守其最小协议；本轮未认证任意第三方后端。

### 6.5 控制及HVDC

幅值不变Clarke/Park满足无零序P=1.5(vd id+vq iq)，零序丢弃的变换不能承诺任意abc无损往返。SRFPLL先用旧ω推进同刻θ，再用同刻v求归一化q误差更新下一ω；这是声明的显式时序，无意外多一步延迟证据。误差为vq/max(|vd|,|vq|,1V)，遥测与内部PI一致。PI按Ki e h方向冻结，低通为BE，SampleDelay按调用次数而非固定秒延迟。

VSC电流正向AC→converter，L did/dt=vgd−vcd+ωLiq，因此vcd*=vgd+ωLiq−PI(Id*−Id)，q轴交叉项取负；源码一致。低Vdc增加吸收Id，低Vac增加容性Iq参考；电流参考圆与最终电压矢量限幅明确，AUD-004只指出缺直接状态恢复测试。

桥端口Pac=Pdc+ΣGsw Vsw²，不能拿电抗器外侧Pac替代桥端；DC双极L/C与BE额外数值耗散单列。系统测试独立重算这两项，RMS/MAE与Vd极性坏波形负例防止有符号均值抵消。FAST每载波50步，边沿按EMT采样；FULL/BENCHMARK还改变PWM频率及故障时序，跨MODE对照不能声称纯步长收敛。

参考映射区分Reference参数与PyCy-adjusted控制、简化双向电导、RC清除缓冲；未声称与商业EMT等价。默认故障清除约3MV级高压峰值属于声明简化电路，不具绝缘配合/保护设计意义。本轮不调80/1000增益，不采用历史已拒绝Kp=40候选。
