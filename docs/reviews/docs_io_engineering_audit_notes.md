## 3. 建议保留的设计与已修历史问题

- `CaseDefinition → Circuit → Simulator → SimulationResult` 路径短而明确。`run_case()` 只组织结果输出，不拥有另一套电气状态机；无需再增加算例工厂、会话框架或命令层。
- `OutputOptions`、`PlotSpec` 采用小型 frozen dataclass，参数名直接描述行为。输出预检在求解前完成，支持相对子目录并核对解析后的归属；实际字段可由回调动态产生，绘图时再检查字段合理。
- 指标按实际时间加权，线性斜坡均方积分为 `h(a²+ab+b²)/3`，乘积积分为 `h(2ac+ad+bc+2bd)/6`。实现与独立多项式积分相符。事件右侧单行不足以还原左极限时拒绝跨事件积分，优于假设连续后给出精确数字。
- 平衡正弦条件下三相无功 `1.5(vβ iα−vα iβ)` 与滞后电流正无功约定一致；瞬时有功直接逐相相加，包含零序。文档已明确平均 P/Q 推出的视在功率不是一般畸变/不平衡功率质量定义。
- RMS/均值/乘积均值缩放及最终有限性检查保留。当前没有理由替换这些关系或放宽测试容差。
- 缺字段统一为 NaN，CSV 空字段、JSON null、NPZ NaN 的往返规则明确；Infinity 用标准 JSON 字符串表示，仍兼容旧裸常量。分析拒绝非有限信号，不能用存档成功替代可分析性。
- NPZ 读入使用 `allow_pickle=False`，在组装 rows 前检查一维、实数 dtype、长度和列名，避免旧长列截断/短列越界问题；四个保留名写前拒绝。
- 失败绘图使用 finally 关闭 Figure；Markdown 报告转义文本并以报告目录计算图片链接。原 I21–24/I27–33 已有实现与正式测试，本轮没有重新包装成新缺陷。
- 当前 Ruff 和 mypy 的范围适合教学项目：选定高收益规则、不强制格式化与行宽、宽松检查已有类型，不必立即全仓严格类型化。
- CI 已含 Linux/Windows、Agg、超时、锁定依赖、全量含 slow 覆盖、全部默认示例、构建及源码目录外 wheel 冒烟；没有根据历史“仅 Linux”结论误报当前配置。

本审在上述实现模块中未确认新的合法输入数值/读写损坏缺陷。此结论只覆盖审查与现有证据，不能证明任意数据文件和任意用户回调均正确。
