# 27：有限电阻 Bergeron 线路验收协议

本协议在候选创建、运行和商业误差计算前冻结。已完成的原生运行用于核实参数、日志和输入；运行成功不代表参考自细化通过，更不代表算例完成。正式窗口和阈值以 [manifest.json](manifest.json) 为准，物理参数及方向以 [parameters.json](parameters.json) 为准。

## 来源与适用范围

[PSCAD 官方 Bergeron 理论](https://www.pscad.com/webhelp-v5-ol/EMTDC/Transmission_Lines/The_Bergeron_Model.htm) 将线路分为两段无损线，并在两端各置 R/4、中间置 R/2。本例保留安装示例 `Lightning/Steep_Front.pscx` 中标量 `SrvcCbl` 的完整线路定义，显式建立独立源、100 Ω 源阻和400 Ω 负载。它是由示例派生的标量基准，不是原闪电工程整机验证。

实际生成的 TLI、TLO、长度和参数单位共同确认总 R=100 Ω、Z=201 Ω、总延迟300 µs。候选只组合现有 `Resistor` 与两个 `BergeronLine`：25 Ω、150 µs 无损半线、50 Ω、150 µs 无损半线、25 Ω；两个半线 attenuation=1。不能用单条衰减线代替电阻分配。高频损耗近似关闭；LCP 频域复阻抗及频域传播时间单独留存，不替换运行参数。结论仅覆盖这一单频参数、集总损耗 Bergeron 近似，不能推广为宽带真实电缆精度。

## 接口、初值和完整时间域

`Vs(t)` 在0.5 ms前为0，0.5–0.6 ms线性升至1000 V，此后保持。每个半线负时间的电压、电流历史均为0，t0正常求解，无稳态预置。候选固定1 µs步长，0至6 ms共6001点，每个半线延迟150步；源拐点、结束点及窗口边界均在网格上。不得移动输入、改延迟、插入短步或删除首尾点。

原生六通道顺序为 Mag、Vs、Vk、Vm、Ik、Im_out，单位分别为kV/kV/kV/kV/kA/kA；归一化统一乘1000，时间保持秒。Vk、Vm对地；Ik由源阻进入完整线路，Im_out由完整线路流向负载。候选对应 `v:send`、`v:recv`、`i:Rs`、`i:Rload`。半线 receiving 电流指向半线内部，不能直接当作正向 Im_out。

两连续窗口为[0,1.2 ms]、[1.2,6 ms]，包括全部启动、波前、反射和末点，无事件排除、零时移。四量每量每窗同时满足 NRMSE≤0.001及最大绝对误差：电压1 V、电流0.005 A；固定工程尺度1000 V和5 A，不采用波形自身峰峰值。连续视图采用原始样本的分段线性函数，保留所有节点，积分采用时间加权误差；最大误差覆盖两曲线所有拐点及边界。源 `v:src` 与实际记录的 Vs另行逐点/连续核对，最大误差≤1e-8 V；Mag仅作参考输入审计。

原生 STANDARD、无快照，以及六量在0.5 ms前全零和收端正确因果到达，支持零历史解释；内部延迟缓冲未直接导出。这一可观测初始化边界必须出现在最终报告，不得表述为隐藏状态已逐项实测。

## 内部独立验证

在现有 `CaseDefinition → Circuit → Simulator → SimulationResult` 路径上组合元件，不改通用核心。另写物理端口递推作为独立检验：每半线两端取入射波a、出射波b，有v=a+b、i=(b−a)/Z，另一端出射波延迟150 µs成为本端入射波；各电阻用欧姆定律联立边界。该递推不能调用候选stamp、历史读取或候选求解器。全网格电压误差≤1e-7 V、电流误差≤1e-9 A；KCL≤1e-9 A、KVL≤1e-7 V。

须单独检查零历史、第一发送区间Vk=(201+25)Ik、收端首次变化位于0.801 ms（源首个非零采样0.501 ms加300 µs），以及首个未返回反射区间的系数
`Vm(t)/Vs(t−300µs) = [800/626] [402/452] [201/326]`。
系数只由已冻结参数推导，不能由商业波形拟合。末态应趋近 I=1000/(100+100+400) A、Vk=1000−100I、Vm=400I；末态不能替代全暂态验证。

逐时核对所有正电阻损耗和两个半线的非负储能。每半线储能为过去一个半线延迟区间内两个出射电压波平方积分之和除以Z。源功率使用−Vs·i:Vdc；源工作须等于Rs、25/50/25 Ω及Rload的损耗积分加两半线储能变化。按分段线性电压/电流精确积分乘积和平方，不把二次功率当线性函数梯形积分。残差限值为 `1e-9 J + 1e-8*max(1 J, integral(abs(source_power)), total_resistor_loss, maximum_line_energy)`。

内部步长用2、1、0.5 µs，各自对独立递推核查完整窗口；传播与源拐点都对齐时允许达到舍入误差，不强求虚假的二阶误差比。测试应覆盖非整数延迟、延迟小于一步、不对齐结束/实际事件、非有限或非法参数，并确认非法网格在首次求解前拒绝。现有零损耗/开短路边界测试可复用，但不能代替本例含100 Ω线路损耗的检查。
