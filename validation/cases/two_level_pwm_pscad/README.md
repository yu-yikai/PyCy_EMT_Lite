# 既有12的PSCAD对标

本目录验证原12号三相两电平PWM算例，不增加教学编号。教学脚本及核心求解器保持原样；
对标程序复用现有波形比较、RMS和基波计算函数。

## 参考电路

400 V直流源连接六只互补控制的双向电阻开关，驱动浮动星形RL负荷。
每相为1 Ω、1 mH，初始电流为0；电流正方向由桥臂流向负荷。
开关导通电阻为1 mΩ，关断电导为1 nS。
控制采用60 Hz、调制比0.8的正弦参考与1 kHz三角载波，参考每100 µs更新。
施加门极每5 µs保持，电气积分采用梯形法。

PSCAD参考使用独立连接的标准元件与算术块，检验同一组理想化假设。
它不包含IGBT正向压降、自动二极管或死区，结论限于这里声明的双向开关模型。
原MathWorks IGBT/二极管模型的[波形失败报告](../two_level_pwm/README.md)继续保留。
两份参考的控制时序和器件假设不同，应分别阅读其结论。

## 已完成的参考检查

真实PSCAD以5 µs和2.5 µs电气步长各运行至.200005 s，取得40002和80003行。
两次施加门极的保持周期均为5 µs；全部共享点输入相同，细步中点保持正确。
原始60通道、初值、连接、生成代码、KCL/KVL和逐步电感方程都经过独立检查。
多出的5 µs尾步使固定.2 s端点有真实相邻样本覆盖，全部原始时间与尾步保留。

粗细参考全窗最大电流差约0.333 A，稳态最大NRMSE约0.092%，
RMS、基波相位和正向负荷耗散也通过预设自细化标准。
完整参考的[资格摘要](qualified_reference_report.json)绑定原始归档及独立审查，
归一化电流仅作kA→A换算。原12的正式比较目前尚未执行。

## 固定比较方法

正式窗为.1–.2 s，包含六个60 Hz周期。每相波形以150 A为基值，
NRMSE限2%、最大误差限10 A；总RMS、基波RMS和负荷电阻平均耗散限5%，相位差限3°。
指标使用原始绝对时间及分段线性积分，不拟合时间、幅值或频率。
完整定义见[验收说明](acceptance_plan.md)和[参考协议](reference_protocol.json)。

在具备完整本地合格参考记录的仓库中运行：

```powershell
$env:MPLBACKEND='Agg'
uv run --locked python -m validation.cases.two_level_pwm_pscad.compare
```

程序先核资格、全部输入文件与时间轴，再运行原12；结果写入唯一的
`local_reference/two_level_pwm_pscad/comparison_results/`子目录，保存数据、叠图和报告。
比较期间无需启动PSCAD。缺失或变化的参考会在候选运行前拒绝，不以内部计算替代商业输出。
第三方工程、波形及完整本地证据保持在忽略目录中。
