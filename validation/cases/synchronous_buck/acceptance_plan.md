# 同步Buck：实现前验收协议

2026-11-06。在26候选及其tests均不存在时固定。本例展示启动、连续PI对应的离散教学实现、同步续流与2A负荷阶跃；不扩自动二极管或控制框架。
来源和前置真实状态证据见[研究补充](../../../docs/development_roadmap/experiments/synchronous_buck_state_followup.md)。全部电路、非零初值、方向、更新顺序及solver数值见[parameters.json](parameters.json)，限值见[manifest.json](manifest.json)。

1. 原完整10ms、30V→双管→L并10k→C/电阻/脉冲负荷。每管100k snubber保留；候选使用IdealSwitch的Goff=0和外部snubber，不重复增加默认漏电。初值按阻断DC网络计算，不能读商业文件作为教学输入。t0两管关，之后严格互补。
2. 候选TR50ns（每载波400步），每次解后更新LP后退欧拉→PI新积分→外Limiter；无内部PI限值/抗饱和，载波在stamp时评价。负荷四边沿作为本例显式事件，先积分到左侧，再固定L/C状态求右侧代数量。不得以source函数在事件前提前施加新电流。
3. 连续电压/电感电流覆盖0..2.5ms和2.5..10ms两个完整窗。公共PWL积分指标仅用于这两个连续物理状态；原事件日志和全部采样保留，不能把对跳变量的禁止规则任意撤销。电压0.3V上限是15V的2%，NRMSE0.5%；电流0.15A约8A尺度的1.9%，NRMSE1%。
4. 全部500个绝对载波周期比较平均电压/电感电流/占空比/源流。限值为0.15V/0.08A/0.015/0.1A。50ns为周期0.25%；旧参考独立核根显示绝对周期可有1..3个边沿，首周期含启动额外根。按三个边沿各一格、8A估计，电荷量化偏差约0.06A周期均值，源流0.1A限另容纳连续控制离散误差。正式审计逐周期使用实际根数，不假定均为两根。未以候选输出确定这些限值。
5. 连续量原生记录按PWL积分；候选duty按其实际左保持积分。原生稀疏Isrc在模式改变后可能晚数µs才记录新侧值，不能直接PWL积分。参考源流周期均值改由真实iL/UC/duty重建：联合PWL状态网格加入解析载波拐点，求全部duty-carrier根，再按每个互补模式的中点KCL逐段精确积分。原Isrc全点及模式改变bracket独立保留，根附近左右值歧义如实报告，不拟合根/相位。重建明确标识为原生状态和拓扑的派生量，不称直接门极或直接Isrc日志。duty插值对根时刻及电荷的条件预算另审计，每周期2e-8C（均值0.001A）；真实baseline/refined源流周期均值还须满足0.01A自细化预算，不能仅靠solver容差宣称绝对精度。脉冲电流按已核事件解析，不画斜坡。原始值及重复时间先完整保存；标准化只取同一时刻最后值，不移时/相位。
6. 两次完整原生ode23tb按parameters的100/50ns、Rel1e-7/5e-8、scalarAbs1e-12/5e-13、AutoScaleAbsTol off运行。参考自细化需满足候选每一连续/周期限值的十分之一。默认旧run只为研究，不替代正式baseline；每次原始MAT先保存、独立目录/输入快照/版本/hash齐备。
7. 重新核实际非零初值、PI坐标映射、互补模式、每段二极管有效域余量；自细化只是可信数值证据，不声称严格绝对误差证明。候选每点及独立物理分析同样需在域内；超域即拒绝此等效，不能新增二极管框架强行通过。
8. 内部验收需独立两状态KCL方程（不调用生产stamp）、单模式线性解析解、控制/事件顺序、储能/损耗平衡、50→25ns收敛，且不得由商业CSV产生oracle。正式例独立Agg执行、全部自动测试与常规质量检查、真实比较图/报告、教学和Git提交均完成才记completed。

若有预定限值失败，保留原始完整失败报告。只在独立物理证据支持且正式重验前另提交修订协议，不能看结果改窗、阈值或移除启动/开关样本。
