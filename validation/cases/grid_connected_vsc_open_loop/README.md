# 28：并网VSC开环

本例把三相电网经串联电阻、电感接到六开关桥。先观察电路和开关时序，
再进入后续电流闭环学习。两档真实Simscape对标均已通过。[验收结果](validation_report.json)

三相电源为120V相电压有效值、60Hz，前20ms逐渐升压；每相串联1Ω和10mH，
电感初始电流为零。400V直流源跨接两条浮置直流轨，两轨相对地的电压会随开关状态变化。
交流电流以电网流向桥为正；`i:Vdc`以直流源正端流向负端为正，表示电源吸收电流。
开关导通电阻为1mΩ，关断电导为1nS，因此关断漏流仍参与求解。

教学代码沿用`CaseDefinition → Circuit → Simulator → SimulationResult`，共16个现有元件。
主文件按参数、源函数、门极函数、接线和结果展示排列，默认运行0.2s并绘制三张图：
三相电流、A相电网与桥极电压、两条直流轨电压。

```powershell
uv run python examples/28_grid_connected_vsc_open_loop.py
```

调制参考的幅值和相角每100µs更新，门极每5µs比较一次1kHz三角载波后保持。
上管满足“参考≥载波”时导通，下管取互补值；初始上管全关、下管全开。
电气步长可选5µs或2.5µs；细步长的中点继续使用上一拍门极。
100µs保持只作用于调制参考，三相交流源仍连续变化。
代码先检查时间是否落在支持的电气网格上，再用整数拍号确定保持时刻，
便于看清参考更新、门极更新和电路求解之间的关系。

开环中的调制幅值0.85、相角−5°均预先给定。改变这些参数会改变电流和功率；
这种响应本身不代表功率跟踪或电流调节。

## 验证

来源、方向、初值、四个比较窗和阈值在候选前固定于`parameters.json`、
`reference_protocol.json`及`acceptance_plan.md`。参考是实际建立并运行的本地
R2025a Simscape模型；5µs和2.5µs两档已经通过参考自身资格检查。
原始模型、MAT和波形保存在忽略的`local_reference/`，教学运行不需要它们。

有完整本地归档时可执行：

```powershell
$env:MPLBACKEND='Agg'
uv run python -m validation.cases.grid_connected_vsc_open_loop.compare
```

比较入口核对参考文件hash，保存独立输入快照，检查实际接入的元件和回调，
再运行两档候选。验证采集到0.200005s，保留全部40002/80003点及尾点。
同一步长按原行号比较；跨步长对连续量积分，对跳变量保留全部共享点硬检查。
物理核还逐点检查KCL、KVL、完整梯形关系、功率及每个能量前缀。
缺少或改变参考文件会报错。

列名中的`_kV`、`_kA`沿用冻结导出表身份，读取时统一换算一次为SI。
实际结果的原始CSV/NPZ和用于末位精度检查的32量CSV分别保留；
时间不平移，开关状态取实际输出，直流电流直接取`i:Vdc`。
详细检查集中在本目录，教学主文件只保留理解电路所需的内容。

默认运行完成40001个采样点，1573项回归测试（含slow）全部通过。
5µs和2.5µs档的共模误差上界分别约为0.310070µV和0.011836µV，原阈值为2µV。
两套独立检查均通过19项物理门、两档同档比较和跨档比较。
试着调整调制相角，观察稳态相电流和功率。验收结果对应默认参数。
